# Money Flow

Учёт доходов и расходов. Один статичный экран: добавляешь траты и доходы, видишь баланс, структуру расходов и график по дням.

- Данные хранятся локально в браузере (localStorage), никуда не отправляются.
- Работает офлайн: после первого открытия кэшируется service worker'ом.
- На iPhone: Safari → «Поделиться» → «На экран Домой».

Экспорт/импорт JSON — для бэкапа и переноса между устройствами.
